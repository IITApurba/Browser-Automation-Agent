# Low-Level Design

Companion to [`docs/HLD.md`](HLD.md). This covers concrete schemas, state shape, the graph's routing logic, module contracts, and API request/response shapes as implemented.

## 1. Database schema (`packages/db/models.py`)

| Table | Key columns | Notes |
|---|---|---|
| `tasks` | `id`, `name`, `goal`, `extraction_schema JSONB` | Reusable task definition; a task can have many runs |
| `runs` | `id`, `task_id FK`, `status`, `plan JSONB`, `current_step_index`, `final_report_id FK`, `error_message` | `status`: `pending / running / paused_captcha / paused_error / completed / failed` |
| `steps` | `id`, `run_id FK`, `index`, `type`, `input JSONB`, `output JSONB`, `status`, `dom_fingerprint`, `screenshot_path`, timestamps | Append-only; one row per graph transition |
| `checkpoints` | `id`, `run_id FK`, `step_id FK`, `reason` (`captcha`/`error`/`manual`), `page_url`, `storage_state JSONB`, `extracted_so_far JSONB`, `scratchpad_memory JSONB`, `resolved_at`, `resolved_by` | Full resumable snapshot |
| `extracted_data` | `id`, `run_id FK`, `step_id FK`, `schema_name`, `data JSONB`, `source_url` | One row per extracted record |
| `reports` | `id`, `run_id FK`, `format`, `file_path`, `summary` | Generated by the `reporter` node |
| `credentials` | `id`, `site_domain`, `username_ref`, `auth_type` | `username_ref` names an env var; no secrets stored in-row |
| `sessions` | `id`, `credential_id FK`, `storage_state JSONB`, `expires_at`, `valid` | Playwright `storage_state` reuse across runs |
| `memory_entries` | `id`, `run_id FK` (nullable = global), `key`, `value JSONB`, `embedding` (optional) | Cross-run structured memory, e.g. cached selector repairs |

All tables use SQLAlchemy 2.0 async declarative models with `sqlalchemy.Enum` for status/type columns (a stdlib `enum.Enum` was tried first and broke Postgres enum binding — see commit history / build report).

## 2. Agent state (`packages/agent/state.py`)

```python
class AgentState(TypedDict):
    task_goal: str
    extraction_schema: dict | None
    plan: list[dict]
    current_subtask_index: int
    scratchpad: dict
    last_action_result: dict | None
    error: str | None
    retry_count: int
    captcha_detected: bool
    checkpoint_id: str | None
    extracted_data: list[dict]
    run_id: str | None
```

This is the exact object threaded through every LangGraph node and the object reconstructed from a `Checkpoint` on resume.

## 3. Graph topology (`packages/agent/graph.py`, `packages/agent/routing.py`)

Nodes: `planner`, `worker`, `replanner`, `captcha_handler`, `reporter`.

Routing (`route_after_worker(state) -> str`), evaluated after every `worker` step:

```
captcha_detected == True                      -> "captcha"        -> captcha_handler -> END (paused)
error is set AND retry_count < MAX_RETRIES(3)  -> "error_retry"    -> replanner -> worker
error is set AND retry_count >= MAX_RETRIES    -> "error_exhausted"-> reporter (partial) -> END
current_subtask_index + 1 < len(plan)          -> "more_subtasks"  -> advance_subtask -> worker
otherwise                                      -> "done"           -> reporter -> END
```

`advance_subtask` is a plain state transform (`current_subtask_index += 1`), not an LLM call — kept cheap and deterministic on the hot path.

## 4. Execution/persistence service (`packages/agent/runner.py`)

`GraphRunner.run(task, run_id, ...)`:
1. Builds the initial `AgentState` from the `Task` row.
2. Drives the compiled graph with `.astream()`.
3. On every yielded transition, writes one `Step` row (`index`, `type`, `input`/`output`, `status`, `dom_fingerprint`, `screenshot_path`) and updates `Run.current_step_index`.
4. On entering `captcha_handler`, writes a `Checkpoint` row and sets `Run.status = paused_captcha`, then stops draining the stream.
5. On reaching `reporter`, sets `Run.status = completed` (or `failed` if the terminal reason was `error_exhausted`).

`GraphRunner.resume_from_checkpoint(checkpoint_id)`:
1. Loads the `Checkpoint` row, deserializes it back into an `AgentState` (plan, scratchpad, extracted_data) and restores the Playwright `storage_state` into a fresh browser context.
2. Because LangGraph's compiled graph doesn't natively resume mid-node without a configured checkpoint-saver, the runner re-enters the **worker/routing loop directly** — calling `worker(state)` then `route_after_worker(state)` in a plain Python loop — rather than re-invoking `.astream()` from the start. This is a deliberate, documented deviation from using LangGraph's own checkpointing primitive, chosen because our `Checkpoint` model already captures everything needed and driving the loop directly is simpler than wiring a second persistence mechanism.
3. Continues until the loop reaches a terminal state (`reporter` or another pause), persisting `Step`/`Checkpoint` rows exactly as `run()` does.

## 5. Browser toolkit (`packages/browser_tools/toolkit.py`)

`BrowserToolkit` (async, one instance per run/session):

| Method | Contract |
|---|---|
| `navigate(url)` | Goes to `url`, waits for `load`, returns final URL + status |
| `click(selector_desc)` | Resolves `selector_desc` via `selector_strategy.resolve()`, clicks, returns success/failure |
| `type_text(selector_desc, text)` | Resolves + fills; does not log `text` if flagged sensitive |
| `extract(schema)` | Runs schema-driven extraction (see §7) against the current page |
| `screenshot()` | Returns a file path under a run-scoped screenshots directory |
| `wait_for_selector(selector_desc, timeout)` | Explicit wait, same resolution chain as `click` |
| `dom_snapshot()` | Returns a pruned HTML string (scripts/styles stripped, depth-capped) for LLM consumption during selector repair |
| `solve_captcha_handoff()` | No-op marker action — the actual pause/resume is orchestrated by the agent, not the toolkit |

This class is imported directly by both `packages/agent/nodes/worker.py` and `packages/mcp_server/tool_definitions.py` — no wrapper duplicates its logic.

## 6. Selector resolution (`packages/browser_tools/selector_strategy.py`)

Ordered fallback chain, first success wins:

1. Explicit CSS/XPath, if the caller supplied one.
2. Playwright role-based locator (`get_by_role`) using an inferred accessible name.
3. Text-based locator (`get_by_text`), partial match.
4. Attribute heuristics (`data-testid`, `name`, `aria-label`).
5. Retry with backoff (covers async-rendered/SPA hydration delays).
6. LLM-assisted repair (extension point): send `toolkit.dom_snapshot()` + the original text description to the configured LLM, validate the candidate exists before acting, and cache a hit in `memory_entries` keyed by site+description so subsequent runs skip straight to step 1 with the cached selector.

## 7. Extraction and reporting (`packages/extraction`, `packages/reporting`)

- `extraction/schemas.py` — per-task Pydantic models describing the fields to extract (name, type, optional CSS hint).
- `extraction/extractor.py` — given a schema and a page/DOM snapshot, first tries direct CSS-hint extraction, falls back to LLM-structured extraction against the pruned DOM text when hints are absent or return nothing.
- `reporting/generator.py` + `templates/report.md.jinja` — renders a Markdown report from `Run` + `extracted_data` + `steps`, saved to disk and recorded as a `Report` row.

## 8. CAPTCHA detection (`packages/browser_tools/captcha_detect.py`)

Heuristic, no ML: checks for known markers (`iframe[src*=captcha]`, `.g-recaptcha`, `#turnstile-wrapper`-style ids/classes) and a text scan for phrases like "verify you are human". Returns a boolean + matched-marker metadata, which `worker` writes into `AgentState.captcha_detected` for routing.

## 9. API contracts (`apps/api/routers/`, `apps/api/schemas/`)

| Method | Path | Request | Response |
|---|---|---|---|
| `POST` | `/tasks` | `{name, goal, extraction_schema?}` | `Task` |
| `GET` | `/tasks` | — | `Task[]` |
| `GET` | `/tasks/{id}` | — | `Task` |
| `POST` | `/tasks/{id}/runs` | `{}` | `Run` (status `pending`, execution scheduled as background task) |
| `GET` | `/runs` | `?status=` | `Run[]` |
| `GET` | `/runs/{id}` | — | `Run` (includes `plan`, `current_step_index`) |
| `GET` | `/runs/{id}/steps` | — | `Step[]` |
| `GET` | `/runs/{id}/stream` | — | `text/event-stream`, one SSE event per new `Step` (implemented as a polling async generator over the `steps` table; Redis pub/sub is the noted upgrade path, not required for v1 to function) |
| `GET` | `/checkpoints` | `?resolved=false` | `Checkpoint[]` |
| `POST` | `/checkpoints/{id}/resume` | `{}` | `Run` (status back to `running`, triggers `GraphRunner.resume_from_checkpoint`) |
| `GET` | `/runs/{id}/report` | — | `Report` metadata |
| `GET` | `/runs/{id}/report/download` | — | File download |

## 10. MCP tool surface (`packages/mcp_server/tool_definitions.py`)

Each tool is a direct `await` call into the shared `BrowserToolkit` instance, decorated with `@mcp.tool()` in `server.py`: `browser_navigate`, `browser_click`, `browser_type`, `browser_extract`, `browser_screenshot`, `browser_wait_for_selector`, `browser_get_dom_snapshot`, `browser_login`, `browser_captcha_status`. `run_stdio.py` is the process entrypoint an MCP client (Claude Code config) launches.

## 11. LLM provider factory (`packages/agent/llm.py`)

`get_llm()` reads `LLM_PROVIDER` (`openai` / `anthropic` / `fake`) and returns a LangChain-compatible chat model. The `"fake"` provider returns deterministic, hand-coded responses shaped like real planner/replanner output, which is what lets `tests/integration/test_full_run_fixture_site.py` exercise the entire graph without network access or an API key.

## 12. Testing strategy

- `tests/fixtures/site/*.html` — static, self-contained pages (`login.html`, `listing.html`, `form.html`, `captcha_mock.html`) served via `file://` or a local `http.server`, so unit/integration tests never touch the network.
- `tests/unit/` — toolkit actions, selector fallback behavior, CAPTCHA detection on/off state.
- `tests/integration/test_full_run_fixture_site.py` — full planner→worker→reporter run against the fixture site using the `"fake"` LLM provider.
- `tests/demo/run_demo_public_site.py` — documented, manually-run script for a real-site demo (not part of CI).
